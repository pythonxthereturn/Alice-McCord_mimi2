概述:
    一个超小的类似SNN的模型,但是跟SNN，本质上是不是一个东西,
    在最小设备和很小的1G内存中能跑50万神经元,目前这个是个文
    字版本，有视觉和多模态插件正在制作,训练过程中可能有一些噪
    声，这是正常的模型内部赫布学习法神经元在收敛时产生的类似记忆,
    当前算法我们称为Natural Attenuation Spiking Network(NASN).
    具体的算法的原理论文正在制作

环境要求
-----------
- Python 3.8 或更高版本
- 无需安装任何第三方依赖包（仅使用 Python 标准库）


四、使用方法
-----------

1 启动系统（交互式文本处理）
   在终端中执行:
     cd 2D/
     python run_2d.py [容器名称]

   示例:
     python run_2d.py               # 使用默认容器 "default"
     python run_2d.py my_container  # 使用指定容器 "my_container"

   首次启动指定容器时，系统会自动创建新容器并初始化神经元网络。
   已有容器会从文件恢复之前的状态。

2 创建新容器
   在终端中执行:
     cd 2D/
     python create_container.py <容器名称> [神经元密度]

   示例:
     python create_container.py my_container     # 密度默认 1.0 (100%)
     python create_container.py sparse 0.5       # 密度 50%

   神经元密度: 0.0~1.0 之间的浮点数，控制活动神经元的比例。
   密度越高，神经元越多，处理能力越强，计算量也越大。



交互式操作:
 
   操作说明:
     - 输入任意文本，按回车提交
     - 系统会进行一轮或多轮大脑运算，然后输出结果
     - 输入 quit 或 exit 退出程序
     - 退出时自动保存当前容器状态


容器管理
-----------
- 容器文件保存在 2D/containers/ 文件夹，格式为 JSON+gzip (.json.gz)
- 每次退出程序时自动保存当前容器状态
- 下次启动时自动恢复上一次的状态（包括神经元连接网络）
- 可通过 create_container.py 创建多个不同名称的容器


文本编码/解码规则
--------------------
编码 (输入 → 数字列表):
  1. 每个字符 → UTF-8 字节序列
  2. 每个字节 (0-255) → 6位十进制字符串（前面补0）
  3. 每个6位字符串 → 逐位拆成6个 0-9 的数字
  4. 所有数字拼接为输入列表，按 1024 个分块，不足补0
  示例: '你' → [228,189,160] → "000228000189000160" → [0,0,0,2,2,8,...]

解码 (数字列表 → 文本):
  1. 输出层数字 → 每6个一组，拼接为6位数字 → 还原为字节值
  2. 有信号的组优先（从索引0开始）
  3. 累积字节，按 UTF-8 规则解码为字符
  4. 所有字符拼接为输出文本


七、核心算法流程（每轮6步）
-------------------------
  步骤1: 喂入输入层 — 数字列表写入输入层神经元
  步骤2: 全量扩散渲染 — 遍历所有活动神经元，预检查+扩散渲染
  步骤3: 单神经元串行处理 — 退火 → 移动 → 连接生长 → 复渲染
  步骤4: BFS信号传递 — 从输入层出发，经连接路径传播到输出层
  步骤5: 时效更新 — 所有神经元 refractory 更新
  步骤6: 读取输出层 — 输出层神经元值解码为文本
